# 🧪 StudyLab
Interactive simulations for Physics, Chemistry, Math and Biology, so students can *see* concepts instead of just memorising them.

## Run locally
Open `index.html` in a browser. No build step needed.

## Current labs
- Physics: Projectile motion
- Chemistry: Reaction rate vs temperature
- Math: Sine function grapher
- Biology: Punnett square

## Roadmap
More simulations per subject, Bangla/English toggle, quizzes, progress tracking, AI tutor, PWA offline mode.

## Contributing
Add a new lab by adding an entry to the `labs` object in `app.js` (controls, draw, explain, quiz). Pull requests welcome.
